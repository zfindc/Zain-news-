# Sum up 19 November's world news in one image — entry

`main.py` copies the bundled artwork `art.jpg` to `/output/entry.png`.
Python 3.13, standard library only, no network, deterministic output.
Artwork: 1024x1024 JPEG, under 1 MiB, as required.

The artwork is a broadsheet-style front page, "THE WORLD TODAY —
Thursday, November 19, 2026", summing up the day's dominant stories:
the historic Trump–Xi–Putin trilateral summit in Shenzhen (APEC),
the ICJ ruling that Myanmar committed genocide in the Rohingya case,
the ongoing wars in Gaza and Ukraine (including the Crimean Bridge
strike), and Cyclone Akvan approaching India's east coast.
